# Phase 8-2 모델 평가 보고서

**날짜:** 2026-02-23
**모델:** CatBoost v1 (`models/prediction/model_v1.cbm`)
**데이터:** 7,134건 낙찰 데이터 (서울 5개 법원 + 전국)

---

## 1. 요약

| 항목 | 값 |
|------|-----|
| 모델 | CatBoost Regressor (148 iterations, early stopping) |
| 피처 | 수치형 9개 + 범주형 4개 = 13개 |
| 5-fold CV MAPE | **11.8%** (MAE=0.072, RMSE=0.106) |
| 테스트셋 MAPE | **11.2%** (Baseline 12.9% 대비 -1.7%p) |

점수 피처 5개(legal/price/location/occupancy/total)는 낙찰 데이터에 점수가 쌓이지 않아 제외.
재추가 기준: 해당 점수 보유 낙찰 건수 500건 이상.

## 7. discount_rate 의존도 분석

| 조건 | MAPE |
|------|------|
| discount_rate 포함 | 11.2% |
| discount_rate 제외 | 13.2% (+2.0%p) |

- discount_rate 제거 시 +2.0%p 악화 → 다른 피처도 독립적 기여 확인
- 순수 discount_rate 단일 피처 모델이 아님
- fail_count + 범주형 피처가 상업용/다회 유찰 구간의 개선을 담당

## 8. 한계 및 개선 방향

### 현재 한계
1. **discount_rate 지배적** (67.5%): 최저가가 결정되면 예측의 대부분이 결정됨
2. **점수 피처 미사용**: 7,134건 중 점수가 있는 건이 거의 없어 제외
3. **소량 유찰 불안정**: 유찰 7회+ 구간은 데이터 부족으로 예측 불안정
4. **tenant/deposit 기여 미미**: 대부분 0이라 분별력 없음

### 개선 방향 (향후)
1. **점수 피처 단계적 재추가**: 낙찰 건수 500건 이상 축적 시 price_score부터 재추가
2. **데이터 축적**: 현재 7,134건 → 매일 자동 수집 중, 3개월 후 10,000건+ 기대
3. **재학습 자동화**: 월 1회 자동 재학습 스크립트 (cron)
4. **피처 확장**: 면적, 층수, 건물연식 등 건축물대장 기반 피처 추가 가능

---

## 9. 결론

- CatBoost v1은 naive baseline 대비 **MAPE 1.7%p 개선** 달성
- 특히 **상업용(-5.8%p)**, **유찰 5회(-8.9%p)** 등 이질적/복잡한 물건에서 효과적
- 현재 기존 룩업 테이블(`_PREDICTED_RATIO_TABLE`)을 대체할 수준
- 점수 데이터 축적과 함께 성능 향상 여지 충분
