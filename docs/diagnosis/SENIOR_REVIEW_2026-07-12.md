## 0. 총평 (Executive Summary)

**엔지니어링 완성도는 개인 프로젝트 기준 상위 수준이나, 서비스의 존재 이유인 "법률 리스크 자동 분석"이 출시 이래 실데이터 0건으로 한 번도 작동한 적이 없다.** 코드는 4-pillar 점수 엔진, ML 예측, 배치 파이프라인까지 갖췄지만, 그동안의 공수는 핵심(권리분석 데이터 확보) 대신 주변부(계산기, 페이지 리디자인, 인증)에 반복 투입됐다. Stage 1~3 진단(5월)이 이 문제를 정확히 짚고 배선까지 수리했으나, **두 달이 지난 지금도 실호출이 없어 수리 효과가 검증되지 않은 상태다.**

시장 조사 결과는 오히려 고무적이다. "무료 × 자동 권리분석 × 신호등 단순화"의 교집합은 현재 한국 시장에 없다 (유료 5사는 연 50만~115만원, 무료 서비스는 컨설팅 영업 퍼널, AI 신생사는 유료 + LLM 블랙박스). **KYUNGSA의 설계 방향 자체는 옳다. 문제는 방향이 아니라, 핵심 데이터가 비어 있는데 주변 기능을 계속 다듬어 온 실행 순서다.**

**단 하나만 해야 한다면:** 틸코 등기 분석 50건 실호출(6,000pt) → legal_score 회복 검증. 이것이 뚫리기 전까지 다른 모든 신규 기능 개발은 동결을 권고한다.

## 2. 서비스의 모순점 (선언 vs 실제)

### M1. "법률 리스크가 핵심"인데 법률 데이터가 0건 🔴
CLAUDE.md는 법률 리스크를 최대 가중치 축으로 선언하고 Hard Stop 8종, LegalScorer 495줄, 35개 테스트까지 갖췄다. 그러나 배치 경로는 캐시된 등기 분석만 참조하고(`batch_collector.py:433,882`) 캐시는 0건이므로, **모든 등급/점수가 법률 축 없는 3-pillar 산출물이다.** 프론트는 이를 ⚫로 표시하는데, 상세 페이지 리스크 체크리스트에서 유치권/법정지상권·선순위권리 항목은 아예 **하드코딩 ⚫**(`RiskChecklist.tsx:59-93`)이다. "권리분석 자동화 서비스"가 권리분석 결과를 한 건도 보여준 적 없는 상태.

### M2. 절대원칙 #2 "검증 레이어 없이는 분석 출력 금지" — 검증 레이어가 스텁 🔴
`services/validator/` 4개 파일 전부 docstring만 있는 껍데기이고, `banned_phrases.json`은 존재하나 **로드하는 코드가 0곳**, `tests/test_validator/`도 1줄 스텁이다. 현재 LLM 리포트 기능이 미구현이라 실해는 없지만, "절대 원칙"이 문서에만 존재한다. → 구현하거나 원칙 문구를 정직하게 수정해야 한다 (로드맵 W8).

### M3. 문서가 가리키는 코드가 실제 코드가 아님 🟠
- CLAUDE.md/README 전체가 등기 연동을 **CODEF** 기준으로 서술하나, 3~4월에 **틸코블렛으로 전면 교체**됨 (`tilko_provider.py`, 커밋 3365b20). CODEF 경로 13개 파일은 잔존 코드.
- CLAUDE.md "법률 가중치 0.30" vs 실제 `total_scorer.py` 유형별 가중치 (아파트 0.20 / 꼬마빌딩 0.35 / 토지 0.25).
- "763개 테스트 통과" vs Stage1 실측 692/763.
- CLAUDE.md 진행상황 섹션이 3/27에 멈춰 있어, 이후 틸코 전환·Stage1~3 진단·수리가 공식 문서에 없다. **다음 세션의 AI가 CLAUDE.md만 읽으면 3개월 전 세계관으로 작업하게 되는 구조적 위험.**

### M4. "70%를 걸러주는 서비스"인데 UI는 "물건 찾기" 패러다임 🟡
서비스 철학은 네거티브 큐레이션(볼 가치 없는 것 제거)인데, 검색 페이지 UX는 경쟁사와 같은 필터-검색-목록 구조다. "오늘 걸러진 물건 N건과 그 이유"를 보여주는 화면이 없어, 차별화 포인트가 UI에서 드러나지 않는다.

### M5. 보안 원칙 vs 기본값 🟠
"API 키 하드코딩 금지" 원칙은 지켜졌으나, `config.py`의 `JWT_SECRET="change-me-in-production"` 기본값은 .env 누락 시 토큰 위조를 허용한다. 텔레그램 webhook도 secret 미설정 시 검증을 생략한다. rate limiting 부재.

## 3. 중요도 대비 과투자 분석

가치 흐름 기준으로 보면: **데이터 수집(잘됨) → 리스크 분석(비어 있음) → 표시/계산(과잉 투자)**. 병목 뒤 단계에 공수가 몰렸다.

| 영역 | 투입 흔적 | 판정 |
|------|----------|------|
| 프론트 리디자인 | Phase 9, A, B~F, K-1, K-2 — 검색 페이지만 **3회 전면 재설계**, 죽은 대안 구현 4종(SearchFilters 440줄 등 ~1,000줄) 잔존 | **과투자.** 사용자 1명인데 UI 세대교체 3번 |
| InvestmentCalculator/현금흐름 | Phase G, H-1~5, 현금흐름 페이지 — 호실 테이블, R-ONE 임대료 밴드, 다방 링크까지 | **과투자(단, 자산성 있음).** 벤치마킹상 유일하게 상용 대비 우위인 기능. 더 다듬는 건 중단하고 현 상태로 동결 권장 |
| 인증/텔레그램 인프라 | Phase I, J — OAuth+JWT+즐겨찾기 DB+웹훅 | **선투자.** 즐겨찾기 0건. 알림 발송 로직도 여전히 미구현이라 인프라만 떠 있음 |
| ML 예측 | CatBoost 재학습, 캘리브레이션, top_factors | 중립. 잘 만들었으나 벤치마킹상 이미 테이블 스테이크(지지 ALG 3.0 등). 차별점 아님. 실측 21,394건 쌓였으니 재학습 1회는 저비용 고효율 |
| **등기 분석 실가동** | Stage3 수리 후 **2개월 방치** | **결정적 과소투자.** 6,000pt(약 수만 원)면 검증 가능한데 안 눌렀다 |
| 죽은 코드 관리 | frontend_backup/, *.bak, v0 API, CODEF 13파일, 빈 스텁들 | 과소투자(정리 부채) |

**교훈:** "다음 Phase"가 항상 새 화면이었다. 앞으로는 로드맵 P0(데이터·운영) → P1(UX 정합) 순서로만.

## 4. UI/UX 적합성

### 잘된 것
- 신호등(🟢🟡🔴⚫) 단순화는 **시장에 유사 사례가 없는 올바른 방향** (벤치마킹 §5 참조 — 요이땅 0~100 점수, 리치고 LLM 요약뿐).
- 모바일 대응(MobileNav, FilterDrawer), 다크모드, 현금흐름 계산기의 호실 자동 채움은 상용 수준.

### 문제
1. **3중 평가 체계 혼선 (높음):** 검색=신호등만, 홈=등급(A~D)만, 비교=등급+legal 원점수+ML% 동시. 세 체계의 관계 설명이 어디에도 없다. → 로드맵 W4: 신호등을 유일한 1차 지표로 통일 권고.
2. **⚫ 도배 (높음):** 상세 체크리스트 4~5개 중 2개가 상시 하드코딩 ⚫ + score null 시 추가 ⚫. legal 데이터 0건인 현재, "분석 못 하는 서비스" 인상을 준다. ⚫를 "자동 분석 대상 아님 — 입찰 전 직접 확인 항목"으로 언어를 바꾸면 같은 데이터로 신뢰 인상이 반전된다. → W5.
3. **초보자 페르소나 미충족 (중간):** 툴팁 인프라는 있으나 실제 용어(유찰/명도/인수 권리/말소기준권리/대항력) 연결 0건. "말소기준권리"라는 단어 자체가 프론트 코드에 없다. 페르소나 B(박초보)가 "왜 위험한지" 읽을 장치 부재. → W10.
4. **면책 커버리지 (중간):** DisclaimerBanner가 홈·상세 2곳뿐. 투자 판단에 가장 가까운 현금흐름/비교 페이지에 없음 — 법적 포지셔닝상 오히려 그쪽이 더 필요하다.
5. **기술 부채 (중간):** 'use client' 58%, Pretendard CDN @import(렌더 블로킹), generateMetadata 부재(SEO 전무), FavoriteButton 중복 2벌.

## 5. 시장 벤치마킹 요약

상세: 벤치마킹 전체 보고서는 이 진단의 조사 에이전트 결과를 본 섹션에 요약. 요금 수치는 2021/2024 비교 글 + 일부 공식 페이지 교차 확인 (2026년 현재 인상 가능성 있음).

### 경쟁 지형
| 진영 | 서비스 | 가격 | 권리분석 방식 |
|------|--------|------|--------------|
| 전통 유료 | 지지옥션(월 13.1만/연 114.7만), 옥션원(11.9만), 스피드옥션(8.4만), 태인(6.9만), 탱크옥션(6.3만) | 연 50만~115만원 | 자동 "정리" + 특수물건은 전문가 수동(지지). AI 낙찰가 예측은 이미 보편화(지지 ALG 3.0 등) |
| 무료 | 두인경매(기본 무료), 마이옥션(전부 무료) | 무료 | 분석은 사람 — 컨설팅/입찰대행 영업 퍼널 |
| AI 신생 | 리치고(2025.4 개편, GPT 요약), 요이땅(2026.4 오픈, 위험도 0~100점 + 3사 AI 교차검증), 땅집고옥션(정확도 85.2% + 보증보험 2억), 손품 | 유료(건당/구독) | LLM 자동 분석 — 블랙박스, 전문가들 "특수물건 누락" 경고 보도 존재 |

### 시장 맥락
경매 신규 신청은 2025년 121,261건으로 16년 만에 최대, 2026년 1분기도 13년 만에 최대 (금리·PF발 물량 증가). 2030 세대 응찰 참여도 급증 추세. 반면 업계 1위 지지옥션의 연매출은 ~94억원 수준 — **수요는 커지는데 공급자들은 작다.** 개인 프로젝트가 무료 니치를 파고들 공간이 실재한다.

### 핵심 결론
1. **테이블 스테이크** (이미 상향평준화): 통합 검색, 지도, 권리분석 "정리", 낙찰 통계, 알림, AI 예상 낙찰가. → KYUNGSA의 ML 예측은 차별점이 아니라 구색 맞추기용.
2. **시장의 빈 곳** = KYUNGSA 설계와 정확히 일치:
   - 네거티브 큐레이션("걸러주기")을 하는 곳이 없음
   - 신호등/색상 등급식 단순화가 사실상 공백 (요이땅 숫자 점수가 유일한 근사물)
   - 룰 기반 + 원문 근거 추적이 가능한 투명한 판단 구조가 없음 (LLM 요약 불신 여론이 오히려 순풍)
   - 무료 × 자동 분석 교집합이 비어 있음
3. **포지셔닝 문장:** "유료 사이트 연 50만~115만원 정보 중, 초보자의 첫 질문 — '이 물건 피해야 하나?' — 에만 답하는 무료 필터." 시장 대체 비용 환산: 연 50만원 구독 + 건당 전문가 리포트 8만원.
4. **법적 참고 (판례 기반 정밀 조사 결과):**
   - 허용 경계 (대법원 99도2193, 2001도790): "자료 제시 + 권리관계 확인·설명 + 경제적 가치 정보 제공·조언"까지. 입찰가 결정·입찰표 작성·절차 대리부터 변호사법 109조 위반 (7년 이하 징역).
   - **대법원 2018. 8. 1. 2016다242716: "대가를 받는 개별 물건 권리분석 + 입찰가 제시 + 리스크 상담" 자체를 법률사무로 판단, 해당 컨설팅 계약을 무효화.** → ⚠️ **KYUNGSA_BACKLOG의 유료화 계획("등기부 열람 유료 플랜", "최적 입찰가 유료 블러")은 이 판례의 사정권에 들어갈 수 있다.** 데이터 열람 과금(등기부 원문+기계적 구조화)은 상대적으로 안전하나, "입찰가 제안"을 유료 상품화하는 순간 무자격 법률사무 대가 수수 쟁점이 생긴다. 유료화 전 변호사 자문 필수 (README 0단계 미완 항목).
   - KYUNGSA의 Public 금지어 원칙은 판례 지형과 정확히 정합 — 유지가 옳다. 면책 문구에 더해 "100% 검증" 류 절대 보증 표현을 금지어 목록에 추가할 가치 (과장 광고는 면책으로 방어 불가).
5. **신뢰 스토리:** 땅집고옥션은 "보증보험 2억"으로 신뢰를 상품화. 무료 개인 서비스인 KYUNGSA의 대응은 반대편 — **미탐지율 0% 정책 + 애매하면 Yellow 강등 + 등기 원문 근거 표시**라는 보수적 설계 자체를 전면에 노출하는 것.
